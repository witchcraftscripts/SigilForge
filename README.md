# SigilForge

SigilForge is a web-based tool that transforms written intentions into unique, animated sigils.

It combines simple text processing with geometric mapping to create symbolic designs using alphabet and number-based systems.

## Features

- Convert intentions into sigil-ready character sequences
- Remove vowels and duplicate letters
- Map letters or numbers onto a circular sigil wheel
- Animate sigil creation step-by-step
- Export completed sigils as images

## How It Works

1. Enter an intention or phrase
2. The app processes the text:
   - Removes vowels (optional)
   - Removes duplicate characters
3. Remaining characters are mapped to positions on a sigil circle
4. Lines are drawn between each point to form a sigil
5. The final design can be exported
